# Shelby Gym · vistas previas

[Gestión](https://calderondante.github.io/Shelby-Gym/gestion/) · [Rutinas públicas](https://calderondante.github.io/Shelby-Gym/rutinas/)

Publicación estática para GitHub Pages. `gestion/` es una demostración con datos ficticios y almacenamiento en el navegador; su PIN no protege información real. La aplicación operativa Next.js + Supabase está en `main` y requiere hosting con base compartida.

La actualización del 20 de octubre incorpora actividades por meses o clases, packs sin vencimiento, asistencia con saldo, Instagram, sorteo exclusivo de socios con cierre conservado, gastos y plantillas recurrentes, pagos mixtos, resumen mensual, descarga CSV/vista PDF y campañas en borrador. WhatsApp todavía no está conectado y no se envían mensajes. Los registros anteriores del navegador se conservan.

`rutinas/` es una guía pública de ejemplo, separada de los datos de gestión.
